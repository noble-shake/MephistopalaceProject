# Palace Project

## Introduce

33원정대에서 영감을 받고 제작한 3D 턴제 RPG 게임입니다.
플레이어는 던전을 탐험하면서, 적과 인카운트 형식을 통해 턴제 배틀을 진행합니다.
전투 중에는 적의 공격 타이밍에 맞춰 패링&회피를 할 수 있습니다.

## Implements

Encounter System
- 캐릭터 조작
- 적 유닛 정찰
- 상호작용 오브젝트
- 인벤토리 시스템

Battle System
- Phase 방식의 턴제 시스템
- QTE 이벤트
- Parry & Evade 시스템

Animation 이벤트 및 Skill 시스템
- 애니메이션 이벤트 함수기반의 대미지 적용 
- 스킬 등록
- 적 AI 로직

Sound & Timelne Event
